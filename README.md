# Практическая работа № 2 — вариант 8

Дисциплина: «Конфигурационное управление».

## Цель

Разработать инструмент анализа и визуализации зависимостей
пакетов JavaScript npm.

## Требования варианта

- Настройка через параметры командной строки.
- Анализ указанной версии пакета.
- Самостоятельное получение зависимостей.
- Обход BFS с рекурсией.
- Обработка циклов и фильтрация по подстроке.
- Поиск обратных зависимостей.
- Формирование Graphviz DOT и изображения SVG.
- Вывод ASCII-дерева по переключателю.

## Текущее состояние

Начата подготовка первого этапа:
чтение, проверка и вывод параметров командной строки.
