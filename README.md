# Практическая работа № 2 — вариант 8

Дисциплина: «Конфигурационное управление».

## Текущий этап

Этап 1: минимальный CLI-прототип с конфигурацией.
Программа проверяет семь настроек и выводит их как ключ=значение.
Загрузка зависимостей npm, рекурсивный BFS, обратные зависимости,
Graphviz SVG и ASCII-дерево будут добавлены следующими этапами.

## Запуск в браузере

После загрузки файлов откройте Actions → Check project.
Проверка запускается при коммите и вручную через Run workflow.
В задаче check доступны шаги Run tests, Demonstrate CLI and errors
и Check Python formatting limits. В демонстрации показаны два успешных
запуска и ошибки для всех семи параметров с кодами завершения.
Сторонние Python-пакеты не устанавливаются.

## Требования и локальный запуск

Python 3.10+, Bash для run.sh. Отдельная сборка не требуется.
На этапе 1 не нужны интернет, npm, Node.js и Graphviz.
На GitHub Actions используется Python 3.12.

```bash
bash run.sh --help
bash run.sh --package is-odd --repository https://registry.npmjs.org \
  --version 3.0.1
bash run.sh --package A --repository tests/fixtures/chain.json \
  --version 1.0.0 --test --ascii
```

Также поддерживается python -m src.main с теми же аргументами.

## Семь настроек

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| --package | Имя пакета npm или тестового пакета | Обязательный |
| --repository | HTTP(S) URL реестра или путь JSON | Обязательный |
| --test | Использовать локальный тестовый файл | Выключен |
| --version | Точная версия SemVer | Обязательный |
| --output | Имя будущего SVG | graph.svg |
| --ascii | Режим будущего ASCII-дерева | Выключен |
| --filter | Подстрока для исключения пакетов | Пустая строка |

В выводе --ascii называется ascii_tree. Переключатели --test и --ascii
передаются без значений. Имена npm проверяются на структуру,
нижний регистр и длину до 214 символов, поддерживается @scope/package.
В тестовом режиме имена состоят из A-Z, указанный файл должен существовать.
Содержимое JSON будет анализироваться с этапа 3; на этапе 1 проверяется путь.
Версия — точный SemVer, например 3.0.1 или 1.0.0-beta.1.
latest и диапазоны вроде ^3.0.0 для начального пакета не принимаются.
В тестовом режиме версия пока только проверяется и выводится.
Расширение результата — .svg, родительская папка должна существовать.
Пустой фильтр отключён; фильтр регистрозависимый и не должен исключать корень.
На первом этапе SVG и дерево не создаются, фильтрация не выполняется.

Ожидаемый результат обычного примера:

```text
package=is-odd
repository=https://registry.npmjs.org
test=False
version=3.0.1
output=graph.svg
ascii_tree=False
filter=
```

## Функции src/main.py

- build_parser() — объявляет семь опций и справку.
- validate_package(args) — проверяет структуру имени и его длину.
- validate_registry_url(address) — проверяет схему, хост и пробелы URL.
- validate_url_details(url) — проверяет лишние части URL и порт.
- validate_repository(args) — выбирает проверку файла или URL.
- validate_version(args) — проверяет точную версию SemVer.
- validate_output(args) — проверяет путь SVG.
- validate_filter(args) — проверяет подстроку и исключение корня.
- arguments(argv=None) — читает настройки и сообщает ошибки CLI.
- main(argv=None) — выводит настройки, возвращает 0 при успехе.

argv=None означает чтение командной строки. В тестах передаётся список.
Коды завершения: 0 — успех, 2 — ошибка параметров.

## Структура и проверки

- src/ — исходный код и обозначение пакета Python.
- tests/test_cli.py — 16 автоматических тестов.
- tests/fixtures/chain.json — данные тестового репозитория.
- tests/demo_cli.py — демонстрация успешных и ошибочных запусков.
- tests/check_style.py — размеры строк, файлов, функций и аргументов,
  а также наличие docstring у функций.
- run.sh — запуск CLI и тестов.
- .github/workflows/check.yml — проверки GitHub Actions.
- .gitignore — исключения для кэша, редакторов и генерируемых файлов.

```bash
bash run.sh --tests
python tests/demo_cli.py
python tests/check_style.py
```

Все 16 тестов первого этапа выполняются без сети.
Инструменты проверки не являются менеджерами пакетов и не получают
сведения о зависимостях. Готовый анализ зависимостей здесь не используется.
